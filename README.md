Course Card Component
📌 About the Project

The Course Card is a simple React JS project that displays course information using a reusable React component. It shows the course name, duration, and category using props.

✨ Features
Displays course details in a card layout.
Uses React functional components.
Passes data using props.
Uses CSS for styling.
Supports multiple course cards.
Demonstrates reusable component development.
🛠️ Technologies Used
HTML5
CSS3
JavaScript
React JS
